# Frontend design

Use the product's audience, task, and existing visual language to guide design. Preserve established components and tokens unless redesign is requested. For new designs, choose a coherent direction with deliberate hierarchy, typography, spacing, color, and interaction.

Choose layouts, frameworks, breakpoints, and component patterns to fit the content and repository. Avoid adding infrastructure or copying a generic visual recipe because it appears in guidance.

Make relevant states usable: empty, loading, error, disabled, and success. Preserve semantic structure, accessible names, keyboard operation, visible focus, readable contrast, and reduced-motion support. Adapt layout and controls to the target devices.

Inspect the rendered result at representative sizes and exercise changed interactions when the environment permits. Use the advanced frontend skill when performance, complex state, PWA behavior, or a large token system needs specialized treatment.
