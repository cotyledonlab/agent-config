# Advanced Frontend

Start with the project's existing framework and conventions and the specific problem to solve. For performance work, measure the relevant behavior before changing it. Do not add patterns or infrastructure solely because they appear in the reference.

Consult only the relevant section of [patterns.md](references/patterns.md): performance and images, loading/error states, forms, mobile/PWA, tokens, React architecture, or animation. Locate its headings before reading; do not load the entire catalog by default. Verify framework-specific advice against the project's version when needed.

Use frontend-design when the task also requires visual or interaction design; it is not an automatic companion to every advanced change. Verify the changed behavior with proportionate checks and report the observed result.
